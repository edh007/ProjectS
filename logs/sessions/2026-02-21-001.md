**Phase 3 — GDExtension 래퍼 작성**

#### 설계 결정
- `GDCardDatabase`: Node 싱글턴. `DirAccess::get_files_at("res://resources/cards/")` 로 .tres 로드, C++ `CardData`로 변환, 역방향 조회(`Ref<Resource>`)도 보관. `EffectHandler::set_database(this)` 호출.
- `GDPlayerCombatant`: RefCounted. C++ `PlayerCombatant` value member 소유. C++ 콜백 → Godot `emit_signal`. `setup_deck(Array)` 로 GDScript CardData Resource → C++ CardData 변환. `get_hand()` → Array of GDScript Resource.
- `GDEnemyCombatant`: RefCounted. C++ `EnemyCombatant` + `EnemyData` value member 소유. `setup_from_data(Object*)` 로 GDScript EnemyData Resource → C++ EnemyData 변환. `intent_changed` 시그널이 Dictionary 방출.
- `GDCombatManager`: Node. C++ `CombatManager` value member. `start_combat(Object*, Array)`, `on_card_played(Ref<Resource>, Object*)`, `end_player_turn()`.
